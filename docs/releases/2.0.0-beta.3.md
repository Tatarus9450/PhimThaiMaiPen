# PhimThaiMaiPen 2.0 beta 3

รุ่นนี้ใช้ **ไอคอนเพนกวินถือไมโครโฟนที่สร้างใหม่ ไม่มีตัวอักษรในภาพ** พร้อมหน้าต่างกระจกโทน **น้ำเงินโคบอลต์ / อำพัน / งาช้าง** ไอคอน PNG 512×512 ใช้ทั้งในแอป ตัวติดตั้ง native และ Flatpak

- การติดตั้งใหม่ยังเริ่มดาวน์โหลด **Qwen3-ASR 0.6B ประมาณ 1.89 GB** เมื่อเปิดแอป แสดงความคืบหน้า พร้อมปุ่ม **หยุดดาวน์โหลด / โหลดโมเดลต่อ** หลังดาวน์โหลดครบ ถอดเสียงในเครื่องได้แบบออฟไลน์
- เตรียม `Meta+H` เริ่ม–หยุดพูด และ `Meta+Shift+H` สลับโหมด พร้อมขอสิทธิ์วางข้อความผ่านเดสก์ท็อป ผู้ใช้ต้องตอบหน้าขอสิทธิ์ของระบบ แอปแสดงความพร้อมตามผลที่ได้รับจริง
- ค่าเริ่มต้นสำหรับการติดตั้งใหม่คือ **Qwen 0.6B + Smart Mix + Auto → CPU + วางทันที** เปลี่ยนเป็นตรวจข้อความก่อนวางได้ ผู้ใช้อัปเกรดยังคงโมเดลและการตั้งค่าเดิม
- **GPU / NPU · Beta** แสดงคำเตือนสีแดง เพราะยังอยู่ระหว่างพัฒนา แนะนำ CPU สำหรับการถอดเสียงทั่วไป การตรวจพบอุปกรณ์ไม่ได้แปลว่าโมเดลพร้อมใช้กับอุปกรณ์นั้น
- ยังนำเข้าโฟลเดอร์ **Qwen3-ASR SafeTensors**, **Whisper OpenVINO** และ **Whisper Turbo GGML Q5** ที่รองรับได้ การนำเข้าเก็บต้นฉบับไว้ ไม่รันโค้ดโมเดลภายนอก และไม่ติดตั้ง runtime เพิ่ม

ดาวน์โหลด `PhimThaiMaiPen-2.0.0-beta.3-x86_64.flatpak` และ `SHA256SUMS` จาก [GitHub Releases](https://github.com/Tatarus9450/PhimThaiMaiPen/releases/tag/v2.0.0-beta.3) แล้วเปิดไฟล์ด้วย Discover หรือ:

```bash
sha256sum --check --ignore-missing SHA256SUMS
flatpak install --user ./PhimThaiMaiPen-2.0.0-beta.3-x86_64.flatpak
flatpak run --branch=beta io.github.tatarus9450.PhimThaiMaiPen
```

ต้องใช้ Linux x86_64 พร้อม Flatpak และอินเทอร์เน็ตสำหรับติดตั้ง runtime กับโมเดลครั้งแรก Qwen 0.6B ใช้ RAM ราว 5.3–6 GB ในชุดทดสอบเดิม ต้องเผื่อให้เดสก์ท็อปและโปรแกรมอื่นด้วย ปฏิเสธสิทธิ์แล้วใช้ตรวจข้อความและคัดลอกเองได้ ลองขอสิทธิ์ใหม่จากหน้าตั้งค่า

**ขอบเขต beta:** ทดสอบหลัก Fedora KDE/Wayland; Popup ต้องมี XWayland แพ็กเกจใช้ PyTorch CPU และรวม OpenVINO สำหรับโมเดลทางเลือก ไม่รวม AMD NPU/Vulkan runtime ทดลอง ยังไม่มีรายการบน Flathub หรือ update remote ของตัวแอป ให้อัปเดตด้วย bundle รุ่นใหม่ และเปิด native หรือ Flatpak เพียงตัวเดียว

อ่าน [วิธีติดตั้ง อัปเดต และย้อนรุ่น](https://github.com/Tatarus9450/PhimThaiMaiPen/blob/master/docs/DISTRIBUTION.md) ตัวแอปใช้ MIT ส่วนโมเดลและ dependency ใช้สิทธิ์ของต้นทาง ประวัติเสียงและข้อความยังปิดเป็นค่าเริ่มต้น
