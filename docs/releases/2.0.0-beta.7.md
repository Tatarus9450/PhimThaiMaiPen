# PhimThaiMaiPen 2.0.0 beta 7

รุ่นนี้เน้นให้พูดแล้วได้ข้อความเร็วขึ้น วางข้อความได้เสถียรขึ้น และหน้าตาใหม่ทั้งหมด / Faster dictation, more reliable paste, and a redesigned interface.

Tag `v2.0.0-beta.6` failed to build in CI and was never published; this release contains the same changes plus the build fixes.

## Speed

- The ASR worker now stays warm between dictations instead of reloading the model every time. On the reference machine a cold start took 19.1 s versus 0.17 s of actual inference; warm dictations skip that cost.
- The model is released from RAM after 5 idle minutes and is prewarmed as soon as you start speaking.
- You can start a new recording while the previous one is still processing; it is queued.

## Reliability

- Downloaded models get a persisted integrity check; damaged files are detected before use.
- Job timeouts scale with the length of the audio, so long recordings are no longer cut off.
- Damaged settings files are repaired automatically and the original is kept as a backup.
- Rotating log file (`~/.local/state/phimthai/logs/phimthai.log`; Flatpak: `~/.var/app/io.github.tatarus9450.PhimThaiMaiPen/.local/state/phimthai/logs/`) and a **copy problem report** action.

## Paste and shortcuts

- Wayland cross-app paste falls back to `wl-copy` (data-control protocol, bundled in the Flatpak); if paste is still impossible the text is copied and you are told to press Ctrl+V.
- Duplicate Meta+H registrations (for example native and Flatpak both installed) are detected and can be cleaned up; rapid repeated toggles are debounced.

## Interface

- Dictation popup states: preparing, live input level, pasted, copied, queued, and errors with a hint.
- Thai-first messages throughout.
- New model cards, grouped autosaving settings with a key-capture shortcut editor, a diagnostics checklist, and a first-run wizard.
- Design tokens, Thai typography, WCAG AA contrast, dark mode, and visible focus rings.

## Upgrade notes

- Install either the user **or** the system Flatpak, not both: `flatpak list --app | grep -i phimthai`, then remove the extra one, e.g. `flatpak uninstall --system io.github.tatarus9450.PhimThaiMaiPen`.
- Settings, models and history are preserved.
