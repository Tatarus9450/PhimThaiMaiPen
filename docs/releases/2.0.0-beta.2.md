# PhimThaiMaiPen 2.0 beta 2

ติดตั้งใหม่แล้วเปิดแอป ระบบเริ่มดาวน์โหลด **Qwen3-ASR 0.6B ประมาณ 1.89 GB** ให้ พร้อมแสดงความคืบหน้า กด **หยุดดาวน์โหลด** และ **โหลดโมเดลต่อ** ได้ หลังดาวน์โหลดครบ ถอดเสียงในเครื่องได้โดยไม่ใช้อินเทอร์เน็ต

- เตรียม `Meta+H` เริ่ม–หยุดพูด และ `Meta+Shift+H` สลับโหมด พร้อมขอสิทธิ์วางข้อความผ่านเดสก์ท็อป ผู้ใช้ยังต้องตอบหน้าขอสิทธิ์ของระบบ แอปแสดงสถานะตามผลที่ได้รับจริง
- ค่าเริ่มต้นสำหรับการติดตั้งใหม่คือ **Qwen 0.6B + Smart Mix + Auto → CPU + วางทันที** เปลี่ยนเป็นตรวจข้อความก่อนวางได้ในหน้าตั้งค่า
- นำเข้าโมเดลจากโฟลเดอร์ รองรับ **Qwen3-ASR SafeTensors**, **Whisper OpenVINO** และ **Whisper Turbo GGML Q5** ที่มีไฟล์ครบ โดยคัดลอกเข้าโฟลเดอร์ข้อมูลของแอปและเก็บต้นฉบับไว้ ไม่รองรับโมเดลทุกชนิดหรือโมเดลที่ต้องรันโค้ดภายนอก
- แสดงคำเตือน **GPU / NPU · Beta** สีแดง แนะนำ CPU สำหรับใช้งานทั่วไป Auto ใช้ CPU ในรุ่นนี้ ส่วน backend เสริมยังต้องมี runtime และฮาร์ดแวร์ที่เข้ากันได้
- ผู้ใช้อัปเกรดยังใช้โมเดล โหมดวางข้อความและการตั้งค่าเดิม ไม่ดาวน์โหลดโมเดลที่ลบไปใหม่หรือเปิดคำขอสิทธิ์ครั้งแรกซ้ำอัตโนมัติ

ดาวน์โหลด `PhimThaiMaiPen-2.0.0-beta.2-x86_64.flatpak` และ `SHA256SUMS` จาก [GitHub Releases](https://github.com/Tatarus9450/PhimThaiMaiPen/releases/tag/v2.0.0-beta.2) เปิดไฟล์ด้วย Discover หรือ:

```bash
sha256sum --check SHA256SUMS
flatpak install --user ./PhimThaiMaiPen-2.0.0-beta.2-x86_64.flatpak
flatpak run --branch=beta io.github.tatarus9450.PhimThaiMaiPen
```

ต้องใช้ Linux x86_64 พร้อม Flatpak และอินเทอร์เน็ตสำหรับติดตั้ง runtime กับโมเดลครั้งแรก Qwen 0.6B ใช้ RAM ราว 5.3–6 GB ในชุดทดสอบเดิม ต้องเผื่อให้เดสก์ท็อปและโปรแกรมอื่นด้วย หากปฏิเสธสิทธิ์หรือ portal ไม่รองรับ ยังตรวจข้อความและคัดลอกเองได้ ลองขอสิทธิ์ใหม่จากหน้าตั้งค่า

**ขอบเขต beta:** ทดสอบหลัก Fedora KDE/Wayland; Popup ต้องมี XWayland แพ็กเกจใช้ PyTorch CPU และรวม OpenVINO สำหรับโมเดลทางเลือก แต่ไม่รวม AMD NPU/Vulkan runtime ทดลอง การนำเข้าไฟล์โมเดลไม่ได้ติดตั้ง runtime เพิ่ม ยังไม่มีรายการบน Flathub หรือ update remote ของตัวแอป ให้อัปเดตด้วย bundle รุ่นใหม่ และเปิด native หรือ Flatpak เพียงตัวเดียว

อ่าน [วิธีติดตั้ง อัปเดต และย้อนรุ่น](https://github.com/Tatarus9450/PhimThaiMaiPen/blob/master/docs/DISTRIBUTION.md) ตัวแอปใช้ MIT ส่วนโมเดลและ dependency ใช้สิทธิ์ของต้นทาง ประวัติเสียงและข้อความยังปิดเป็นค่าเริ่มต้น
