# PhimThaiMaiPen 2.0 beta 1

แอปพิมพ์ด้วยเสียงไทย–อังกฤษสำหรับ Linux รุ่น Flatpak beta แรก ค่าเริ่มต้น **Qwen3-ASR 0.6B + Smart Mix** ถอดเสียงในเครื่องและเลือกโมเดลอื่นได้

- หน้าต่าง Liquid Glass พร้อมตั้งค่าไมค์ โมเดลและตรวจแก้ข้อความ
- `Meta+H` เริ่ม–หยุดพูด และ `Meta+Shift+H` สลับโหมดหลังเปิดใช้ปุ่มลัด
- Popup เล็กด้านซ้ายพร้อมเสียงแจ้ง และวางข้อความขณะใช้แป้นไทยหรืออังกฤษ
- โมเดลดาวน์โหลดแยก ตรวจความสมบูรณ์และเก็บไว้เมื่ออัปเดตแอป
- ประวัติเสียงและข้อความปิดเป็นค่าเริ่มต้น

ดาวน์โหลด `PhimThaiMaiPen-2.0.0-beta.1-x86_64.flatpak` และเปิดด้วย Discover หรือ:

```bash
sha256sum --check SHA256SUMS
flatpak install --user ./PhimThaiMaiPen-2.0.0-beta.1-x86_64.flatpak
flatpak run --branch=beta io.github.tatarus9450.PhimThaiMaiPen
```

ต้องใช้ Linux x86_64 พร้อม Flatpak และอินเทอร์เน็ตเพื่อติดตั้ง KDE runtime กับโมเดลครั้งแรก Qwen 0.6B ดาวน์โหลดประมาณ 1.89 GB ใช้ RAM ราว 5.3–6 GB ในชุดทดสอบ และต้องเผื่อให้โปรแกรมอื่นด้วย

หลังเปิดแอป ให้ดาวน์โหลดโมเดล ทดสอบไมค์ เปิดใช้ปุ่มลัดและอนุญาตวางข้อความใน Settings ค่าเริ่มต้นให้ตรวจข้อความก่อนวาง เปลี่ยนเป็นวางทันทีได้ ไม่ควรเปิดรุ่น native กับ Flatpak พร้อมกัน

**ขอบเขตรุ่น beta:** ทดสอบหลัก Fedora KDE/Wayland; desktop portal ต้องรองรับปุ่มลัดและการวาง Popup ต้องมี XWayland รุ่นนี้ใช้ PyTorch CPU รวม OpenVINO สำหรับโมเดลทางเลือก แต่ไม่รวม AMD NPU/Vulkan runtime ทดลอง ยังไม่มีรายการบน Flathub และยังไม่มี update remote สำหรับตัวแอป ให้อัปเดตด้วย bundle รุ่นใหม่
